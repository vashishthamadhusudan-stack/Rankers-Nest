# Rankers Connect — Marketplace MVP

A responsive static frontend for a tutor and institute discovery marketplace.

## Included
- Student learning-requirement form
- Tutor registration form
- Institute registration form
- Subject/exam discovery cards
- Responsive landing page

## Important prototype limitation
The current forms save demo submissions only in the visitor's browser localStorage. They do not transmit enquiries to Rankers Nest. Before using this site for real admissions, connect Firebase (Authentication + Firestore), an admin dashboard, notification delivery, privacy/consent language, and secure payment/commission handling.

## Publish
This project is in the `rankers-connect/` folder of the `Rankers-Nest` repository. If GitHub Pages is already enabled for the repository from the `main` branch and root folder, open:
https://vashishthamadhusudan-stack.github.io/Rankers-Nest/rankers-connect/
